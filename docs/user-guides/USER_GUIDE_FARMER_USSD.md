# User Guide: Farmer — USSD Access

This guide explains how to use the platform via **USSD** (short code) on any mobile phone — no internet or smartphone required. All core farmer actions are available through a simple menu system.

---

## 1. Getting started

1. Dial the platform's USSD short code (e.g. `*123#`) from the **phone number registered** to your account.
2. If this is your **first time**, you will be asked to **create a 4-digit PIN**:
   - Enter your PIN → Confirm it by entering it again.
   - If the two don't match you'll be asked to retry.
3. On subsequent sessions, enter your **4-digit PIN** to log in.
   - You have up to **3 attempts**. After 3 wrong PINs the session ends for security; try again later.
4. If your phone number is not registered on the platform, the session will end with a message to contact your administrator.

> **Tip:** Keep your PIN private. If you forget it, contact your staff admin to reset your account.

---

## 2. Main menu

After entering your PIN, you see:

```
OFSP Menu
1. My Orders
2. Pickups & Delivery
3. Market Info & Prices
4. Buyer Requests
5. Advisories
6. My Stock / Inventory
0. Exit
```

Type the **number** of the option you want and press **Send**.

**Navigation shortcuts** (available on most screens):
- `98` — Go **back** to the previous screen
- `99` — Go to the **main menu**

---

## 3. My Orders

View and manage orders that buyers have placed on your produce.

1. Select **1** from the main menu.
2. You see your **latest orders** (up to 5 at a time). Press **6** to see more if you have additional orders.
3. Select an order (1–5) to view its details:
   - **Buyer** name
   - **Variety** and **grade**
   - **Quantity** and **price**
   - **Status** (e.g. Order placed, Accepted, Payment secured)

**Actions depend on the order status:**

| Order status | Available actions |
|---|---|
| **Order placed** | **Accept** the order or **Reject** it |
| **Accepted** | View **pickup details** (centre, date, route) |
| **Payment secured** | **Confirm payment received** |

After accepting, rejecting, or confirming payment, you return to the order list.

---

## 4. Pickups & Delivery

Book pickup slots at aggregation centres and manage your bookings.

### View schedules and book a slot

1. Select **2** from the main menu → then **1** (View schedules).
2. You see a list of **aggregation centres** near you (up to 5; press **6** for more).
3. Select a centre to see its **available schedules** (dates and times).
4. Select a schedule to see details (date, time, capacity remaining).
5. Press **1** to **book** this slot:
   - Enter the **quantity (kg)** you plan to deliver (must not exceed the available capacity).
   - **Confirm** the booking (press **1**) or **cancel** (press **2**).
6. On success, you receive an **SMS confirmation** with your booking details.

### View and manage your bookings

1. Select **2** from the main menu → then **2** (My bookings).
2. You see your **existing bookings** (up to 5 at a time).
3. Select a booking to see its details (centre, date, quantity, status).
4. From the details screen:
   - Press **1** to **cancel** the booking (if allowed)
   - Press **2** to **confirm pickup** (when you've delivered the produce)

---

## 5. Market Info & Prices

Get a quick view of current market prices.

1. Select **3** from the main menu.
2. You see **today's prices** (KES per kg) for the top varieties currently on the platform.
3. Use this to inform your pricing decisions when posting produce or responding to buyer requests.

---

## 6. Buyer Requests

View open sourcing requests from buyers and submit offers.

1. Select **4** from the main menu.
2. You see the **latest open requests** (up to 5) — these are buyer sourcing requests looking for produce.
3. Select a request to view details:
   - **Buyer** name
   - **Variety** requested
   - **Quantity** needed
   - **Target price** per kg
4. Press **1** to **submit an offer**:
   - You see your **available batches** in inventory (up to 5). Select the batch you want to offer from.
   - Enter your **price per kg**.
   - Enter the **quantity** you want to offer (must not exceed your batch quantity).
   - **Confirm** and send the offer (press **1**) or cancel (press **2**).
5. Your offer is submitted to the buyer for evaluation.

---

## 7. Advisories

Read extension advisories and tips sent to you.

1. Select **5** from the main menu.
2. You see the **latest advisories** (up to 5) — messages from extension officers with farming tips, alerts, or updates.
3. Select an advisory to read its **title** and **content** (truncated to fit the screen).
4. Full advisories may also arrive via **SMS** and **web notification** if you use the web platform.

---

## 8. My Stock / Inventory

View your produce inventory and update listing prices.

1. Select **6** from the main menu.
2. You see your **inventory batches** (up to 5) — each shows batch ID, variety, quantity, and status.
3. Select a batch to view its details and **current price**.
4. Press **1** to **set or update the price** per kg:
   - Enter the new price.
   - The price on your marketplace listing is updated.

> **Note:** Price updates work when you have an active listing linked to the batch.

---

## 9. Quick reference

| Goal | Steps |
|------|--------|
| View my orders | Main → 1 → Select order → View details |
| Accept an order | Main → 1 → Select order → Accept |
| Reject an order | Main → 1 → Select order → Reject |
| Book a pickup slot | Main → 2 → 1 → Select centre → Select schedule → Enter quantity → Confirm |
| Cancel a booking | Main → 2 → 2 → Select booking → 1 (Cancel) |
| Confirm delivery at centre | Main → 2 → 2 → Select booking → 2 (Confirm pickup) |
| Check market prices | Main → 3 |
| Respond to buyer request | Main → 4 → Select request → 1 → Select batch → Enter price → Enter quantity → Confirm |
| Read advisories | Main → 5 → Select advisory |
| Check my inventory | Main → 6 → Select batch |
| Update listing price | Main → 6 → Select batch → 1 → Enter new price |
| Go back | Type `98` on any screen |
| Go to main menu | Type `99` on any screen |
| Exit | Main → 0 |

---

## 10. Tips

- **Sessions time out** after a period of inactivity. If this happens, simply dial the short code again and re-enter your PIN.
- **SMS confirmations** are sent for important actions (e.g. pickup bookings). Check your messages if you need a reference.
- All actions you perform via USSD are also visible when you log into the **web platform** (if you have access).
- If you need help or encounter issues, contact your lead farmer, extension officer, or staff admin.
