# Platform User Guides

This folder contains **role-based user guides** for the OFSP platform. Each guide describes how to use the features and flows available to that user class.

---

## Guides by role

| Role | Document | Description |
|------|----------|-------------|
| **Farmer** | [USER_GUIDE_FARMER.md](USER_GUIDE_FARMER.md) | Post produce, manage orders, book pickups, buy inputs, view analytics |
| **Farmer (USSD)** | [USER_GUIDE_FARMER_USSD.md](USER_GUIDE_FARMER_USSD.md) | Access the platform via USSD on any phone — orders, pickups, market prices, buyer requests, advisories, inventory |
| **Lead Farmer** | [USER_GUIDE_LEAD_FARMER.md](USER_GUIDE_LEAD_FARMER.md) | All farmer features + approve/reject other farmers' produce listings |
| **Buyer** | [USER_GUIDE_BUYER.md](USER_GUIDE_BUYER.md) | Browse marketplace, place orders, manage deliveries, rate farmers |
| **Extension Officer** (County Officer) | [USER_GUIDE_EXTENSION_OFFICER.md](USER_GUIDE_EXTENSION_OFFICER.md) | Dashboard, farmers, quality standards, location summary, reports, advisory (SMS + web) |
| **Staff** (Admin) | [USER_GUIDE_STAFF.md](USER_GUIDE_STAFF.md) | Users, farmer groups, aggregation centres, locations, commodity approval & settings, activity logs, analytics, reports |
| **Aggregation Manager** | [USER_GUIDE_AGGREGATION_MANAGER.md](USER_GUIDE_AGGREGATION_MANAGER.md) | Stock in, receive from ward, stock out, order processing, buyer matching, inventory, reports, farmers |
| **Input Provider** | [USER_GUIDE_INPUT_PROVIDER.md](USER_GUIDE_INPUT_PROVIDER.md) | Input catalogue, orders from farmers, inventory, customers |
| **Transport Provider** | [USER_GUIDE_TRANSPORT_PROVIDER.md](USER_GUIDE_TRANSPORT_PROVIDER.md) | Pickup schedules, transport requests, collection, active/completed deliveries, earnings |

---

## What each guide covers

- **Logging in** and first steps
- **Main menu** and navigation (sidebar items and paths)
- **Feature-by-feature** steps (e.g. how to post produce, place an order, send an advisory)
- **Flows** (e.g. create listing → approval → live; place order → accept → pay → collect → rate)
- **Quick reference** tables for common tasks

Guides cross-reference each other where roles interact (e.g. buyer guide links to farmer guide for the seller's perspective).
