# OFSP Design System - Quick Reference

## 🎨 Color Palette

### Primary Colors
- **Orange 500** `#FF6B35` - Primary brand, CTAs, active states
- **Orange 600** `#E55A2B` - Buttons, links, hover states
- **Green 600** `#16A34A` - Success, agriculture, completed states

### Status Colors
- **Success:** Green 600 `#16A34A`
- **Warning:** Yellow 500 `#FBBF24`
- **Error:** Red 500 `#EF4444`
- **Info:** Blue 500 `#3B82F6`

### Quality Grades
- **Grade A:** Green 600 `#16A34A`
- **Grade B:** Yellow 500 `#FBBF24`
- **Grade C:** Orange 500 `#FF6B35`

## 📝 Typography

### Font Family
- **Primary:** Inter (weights: 400, 500, 600, 700)
- **Fallback:** System fonts (-apple-system, Segoe UI, etc.)
- **Why Inter:** Designed for screens, excellent readability, perfect for agricultural context

### Font Sizes
| Element | Mobile | Desktop | Weight |
|---------|--------|---------|--------|
| H1 | 28px | 40px | 700 |
| H2 | 24px | 32px | 600 |
| H3 | 20px | 24px | 600 |
| Body | 14px | 16px | 400 |
| Body (Farmers) | 16px | 18px | 400 |
| Small | 12px | 14px | 400 |

### Key Features
- **Multi-language:** Excellent Swahili support
- **Screen-optimized:** Designed specifically for digital interfaces
- **Accessibility:** Excellent legibility at all sizes

## 🎯 Usage by User Role

### Farmers
- **Larger text:** 16px minimum
- **High contrast:** Bold headings
- **Simple colors:** Orange primary, Green success
- **Clear CTAs:** Large orange buttons

### Officers/Staff
- **Standard sizes:** Can handle denser info
- **Data visualization:** Charts use orange/green/blue
- **Professional:** Clean, data-focused interface

## ✅ Accessibility
- **Contrast:** All colors meet WCAG AA (4.5:1 minimum)
- **Font scaling:** Supports 200% browser zoom
- **Focus states:** Orange 600 outline (2px)
- **Touch targets:** Minimum 44x44px

## 📱 Mobile Optimization
- **Font loading:** `font-display: swap`
- **Colors:** Tested for bright sunlight visibility
- **Performance:** Optimized font subsets
